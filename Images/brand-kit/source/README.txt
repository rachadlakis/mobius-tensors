Mobius Tensors brand kit generator
Run order: python3 brand.py  ->  node render.js (needs playwright)  -> PNGs in brand/png
Needs Space Grotesk font files (npm pack @fontsource/space-grotesk, extract next to scripts) and fonttools+brotli.
Strip colours are set near the top of brand.py (_A, _B); tagline text "Endless vision. Infinite progress." is in brand.py.
